# SwiftLabor — 3PL Operations Agent Demo

A polished, interactive sales prototype demonstrating how an AI operations agent can handle repetitive shipment-status work while escalating exceptions to a human.

## Demo environment

This repository uses synthetic data for demonstration purposes. It is not connected to LOKI or any customer's production systems.

## Core flow

Customer email → shipment identification → operational checks → exception detection → human approval → action → audit trail.

## Stack

- Next.js / TypeScript
- Tailwind CSS
- Supabase-ready data layer
- OpenAI-ready agent layer
- Vercel-ready deployment

## Product principle

Automate routine work. Keep humans in control of exceptions.
